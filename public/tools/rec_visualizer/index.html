🎯 REC BBox Visualizer 使用指南

1. 什么是 REC (Referring Expression Comprehension)？

REC 即指代目标理解，是大模型（如 Qwen2-VL, Florence-2, InternVL 等）通过自然语言指示在图像中精确定位特定目标物体的任务，输出通常为基于 [0, 1000] 归一化的 Bounding Box 坐标。

2. 支持的坐标顺序

系统默认采用 [ymin, xmin, ymax, xmax]（Qwen-VL 及 Florence-2 标准格式）。如果您使用的是标准检测格式，可在设置中切换为 [xmin, ymin, xmax, ymax] 或 COCO 宽高格式。

3. 图片输入方式

  • 本地文件：点击选择或拖放图片。
  • 直接粘贴：在网页任意位置按下 Ctrl + V 即可立即粘贴剪贴板截图。
  • 在线网页 / 链接：可输入图片直链，或输入普通网页 URL 自动抓取网页快照（便于测试 Web GUI Agent 定位能力）。

4. 手动绘制标注

切换至右上角的“手动绘制框”模式，即可在图片上拖拽拉框，系统会自动生成对应的 [0, 1000] 归一化坐标与标签，方便构建 REC Prompt 与评测数据。
